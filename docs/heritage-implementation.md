快速连续切换采用请求序号丢弃过期图片结果。图片失败保留上一张并提示。无 JavaScript 时保留默认图片和分类导航。寻味山河只有一张茶砖示意图，因此禁用切图和自动轮播按钮，不伪造第二张图片。
