# 《遗脉相承》设计理念 v2：一根线

> 2026 零杯网页设计大赛 · 零组 · 主题二「匠心传承，非遗焕新」
> 本文在初版《设计理念与交接说明》之上深化，初版的考据规矩、技术硬约束、文案禁用词全部继续有效。
> 这里只写三件事：理念往哪深了一层，这一轮改了什么，下一轮从哪接。

---

## 1. 一句话

> **非遗不是一件件东西，是一根从人手里递到人手里的线。这个站让你看见这根线，看见它哪里变细了，然后把线头递给你。**

初版的一句话是「把非遗从展柜里拿出来」。它说清了*不要什么*（展柜），没说清*是什么*。
站名已经改成「遗脉相承」，答案就在名字里：**脉**。

「脉」这个字给了全站一个可以画出来的东西：

| 说法 | 画面 | 在站里的落点 |
|---|---|---|
| 一脉相承 | 一根不断的线 | 首页左侧的朱线，从首屏底一直牵到页尾 |
| 命悬一线 | 线变细、变短、断续 | 首页「叁」的 114 根线，80 分以上的是虚线 |
| 薪火相传 | 线头没系死 | 朱线在页尾那句话旁边停成一个空心结 |
| 脉络 | 时间里的线 | 拍与拍之间的「缝」里露出七千年长卷 |

**判断一个改动对不对，多了一条标准：它是在画这根线，还是在线旁边添东西。**

## 2. 三拍，从全站搬进首页

初版的四拍（看见美 → 还在用 → 快没了 → 我能做什么）分散在四个栏目里，评委必须点完四个页面才能走完。
首页原来只有前两拍，停在一段口号上。

现在首页自己就是一遍完整的走线，各栏目是每一拍的展开（原设计的第四拍「传薪有我」已按评审意见删去，见本节末）：

| 拍 | 首页版面 | 一句题眼 | 展开去哪 |
|---|---|---|---|
| 首屏 | 满幅的拉坯的手，大字压在转盘上 | 岁月中走来，人间中回响 | 底部三格直接预告三拍 |
| 壹 百工有章 | 三篇故事（陶瓷、绒花、木版年画）+ 长卷里的四组人物 | 一器一物，皆有来处 | 非遗辑录 |
| 贰 古艺入常 | 柜台线上的四件新作，写明状态与去处（不标价格） | 旧时手艺，今日生活 | 古艺新生 |
| 叁 遗脉寻踪 | 夜色底，114 根线，可划、可按方向键逐项读 | 循其来路，察其存续 | 存续有数 |

「叁」是全页唯一的深色段，也是情绪最低的地方。它之前两段都是纸色，之后回到纸色，明暗本身就在讲这三拍。

> **修订（2026-11-10）**：评审意见认为原「肆 传薪有我」那四行措施（买一件 / 学一手 / 看一场 / 玩一把）「意义不大，看着很人机，没必要强行写措施」，整段已删除，首页收在「叁」的题记上。首屏四格随之改成三格，手机端竖排成一条。

初版列出的三个已知不足，这一轮顺手解决了两个：

- **时间轴从标题背后透出**：每拍都有不透明的底，长卷只从拍与拍之间的「缝」（`.tl-window`）露出来，缝对到视口中线时从水印提到正常浓度。悬停两端浮起、点击固定的老交互不变。
- **古艺新生入口偏深**：首页「贰」的四件直接带状态、去处和价格，点一下就落到 `revival.html?case=NN` 的档案。

## 3. 视觉：纸、墨、朱，加一层夜色

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f6efe4` | 全站底色（不变） |
| `--paper-deep` | `#ece1cf` | 旧纸。隔开相邻的浅色版面（首页「贰」） |
| `--ink` | `#10100f` | 正文与标题（不变） |
| `--night` | `#16120e` | 夜色，带褐的漆黑。整段深色版面：首屏底、首页「叁」、全站页脚 |
| `--red` | `#a6281f` | 朱。**只画线和标状态**：朱线、下划线、拍号、状态标签、价格 |

规矩收紧了一条：**朱色不再做面，只做线和小标。** 夜色底上的朱提亮成 `#e0705f / #ff7a62`，保证对比度。
长卷四色仍只属于四组入口，首页用它们画四组人物脚下的那道色线，不外溢。

字的用法也收紧：

- **宋刻**负责所有大字，首屏标题到 138px，拍标题到 90px。大气主要靠字号的落差，不靠装饰。
- **行书**只出现在三处：拍号（壹贰叁肆）、页脚题眼、页尾那句话。
- **竖排**只用一次：首屏右上的引语。
- 宋刻的阿拉伯数字偏细，大号数字和价格改用系统衬线（Georgia）。
- 去掉了首屏的英文全大写眉题和「向下探索 ↓」。

## 4. 签名元素

初版的两个签名键（赭红退出、墨绿全屏）保留。新增一个更大的：

**朱线。** 全站三处，是同一根线：

1. 首页左侧 `.pulse`：从首屏底到页尾，随滚动画到视口中线，终点是一个空心结。
2. 每一页页眉底边：读到哪，线走到哪（纯 CSS 滚动驱动，页面不滚动时不出现）。
3. 每一页页脚顶边：一小段朱线，是这根线在这一页的落点。

**不要加第二种贯穿全页的装饰线。**

## 6. 更新后的取舍

| 取舍 | 原因 |
|---|---|
| 首屏从「一句大字」改成「满幅照片 + 大字」 | 初版担心视觉挤掉人；这张图本身就是一双手，是「见人」最直接的证据，署名仍在 |
| 首页不再让时间轴处处透出 | 「只在空白处透出」在实际版面里变成从标题和产品图背后透出，是噪音。改成三道明确的缝 |
| 首页放数据可视化，而不是只放一个去光谱页的链接 | 「快没了」是三拍里最需要亲眼看见的一拍，一个链接传不了情绪 |
| 114 根线不可点开详情 | 详情属于存续有数页；首页只负责让人想去 |
| 「肆」用四行大字，不用卡片 | 行动要像一句话，不像一个功能模块 |

## 7. 还没做的（按性价比排）

1. **栏目页还没接上这套语言。** 非遗辑录、古艺新生、存续有数、分类页的版式这一轮没动，只换了页眉朱线和页脚。下一步建议先统一各页的页头：拍号 + 宋刻大标题 + 一句题眼，去掉 `CATALOGUE` 这类英文眉题。
2. **命名残留**：存续有数已统一（标题「存续有数」，副题「一百一十四项非遗的濒危光谱」）；其余多数页面的 `<title>` 仍以「非遗辑录」结尾，而站名已是「遗脉相承」。
3. **古艺新生的柜台视图偏淡**，六座展柜在 1440 下只占中间一小块，和首页的尺度落差明显。
4. **分类页正文中途没有「它今天长什么样」的交叉入口**（初版已知不足第 3 条，仍在）。
5. **初版交接文档里的站名、首页描述、文件清单需要同步**到本文的口径。
6. 首页「贰」四件新作的价格与去处抄自 `revival-data.js`（核实于 2026-11-05），那边更新后这里要跟着改。
