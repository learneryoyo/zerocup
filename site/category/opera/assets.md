# 戏曲类素材清单

文字内容见同目录 `note.md`（队友整理的项目简介与名录信息）。

## 目录规则

```
site/category/opera/
├── note.md                  文字资料
├── assets.md                本文件
└── <项目名>/
    ├── images/              照片
    └── videos/              短视频
```

页面引用示例（`opera.html` 里写）：

```html
<img src="opera/peking-opera/images/opera-01-painted-face-entrance.jpg" alt="京剧武净勾脸">
<video src="opera/peking-opera/videos/opera-sizhou-city-yangfan.mp4" controls muted playsinline></video>
```
