# 第三页：非遗创新产品案例

五条创新路径，每类六个案例，共三十个。此版本是可独立运行的静态页面，也可把 `index.html` 的主体区块、`style.css`、`data.js` 和 `app.js` 合入团队网站。

## 运行

直接在 Chrome 打开 `index.html`。页面无构建步骤，无外部依赖、CDN、预设样式库或字体包。若嵌入现有站点，需合并同名样式选择器并保留 `data.js` 在 `app.js` 之前加载。

## 新增：叩启新生

左侧标签页新增六个橱窗。每件敲击三次后玻璃碎裂，显示新品揭晓界面并收入图鉴。图片仍为空，详见 `docs/interaction.md`。

- 基准规格：1440px；自适应1920/1440/720。目标：Chrome 129。
- 第三方库：无。
- 当前交付为独立第三页模块，未写入用户电脑的项目目录。

## 当前交互

- 五条路径跳转，各有六张横向滚动卡片；可用按钮、触摸、触控板和键盘左右键浏览。
- 搜索项目名、地区、产品叙述和标签；按 `/` 聚焦搜索框。
- 点击或按 Enter/空格打开完整档案，包含 200—300 字总述、爆点、古今对照、产品档案、标签和资料网址。
- 弹窗支持 Esc 和关闭按钮，关闭后焦点返回原卡片；适配手机和减少动态设置。

## 图片接入

目前三十项的 `image` 全部为 `null`，页面以文字与几何底色占位，**没有假造产品照片**。取得图片使用许可后，把图片放进 `assets/cases/`，在 `data.js` 的对应案例填写相对路径，例如：

```js
"image": "assets/cases/01.jpg"
```

推荐文件名 `01.jpg` 至 `30.jpg`，与案例编号一致。横向照片建议宽 1200 像素以上，卡片区域比例约 2:1；图片会以 `object-fit: cover` 裁切。另建素材台账记录作者、来源网址、许可范围和用途。资料报道中的图片不能仅凭网页可访问就直接使用。

## 比赛规则与内容边界

- 只用原生 HTML、CSS、JavaScript；**使用的非自己编写的库：无**。页面布局、视觉样式、数据结构和交互代码均为本项目编写。
- 2026 零杯手册禁止预设样式库，功能库如使用需在提交时说明。本版本没有引入任何库。
- 五类是本站的创新路径，不是官方非遗分类；案例中的非遗级别针对所依托的代表性项目，产品本身不获非遗认定。
- 资料内容来自同目录之外的《非遗创新产品案例资料_第三页策展.md》，核查日期为 2026-11-01。页面提供原文来源链接，正式发布前复核产品在售状态、项目名及图片授权。
- 当前只是第三页独立模块；没有假定团队其他页面的路由、导航或配色。`index.html` 顶部品牌与导航可在合并时替换。
