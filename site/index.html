这一页现在是什么

这是首页骨架，不是最终成品。它已经接好了全站公共样式 css/base.css，颜色、字体、缓动曲线都定好了， 照着这里的样子往下做就行，不要再自己配色。

改这一页的人：A（把字母换成你自己的名字）

五个颜色，不要加第六个

  • 纸底 --paper
  • 卡片 --card
  • 墨色 --ink
  • 印章红 --red
  • 描金 --gold

写法一律用变量：color: var(--ink);， 不要写 #43372A。以后要整体调色，改一处就行。

python -m http.server 8000

然后浏览器打开 http://localhost:8000
