# 非遗日历 · 身边的非遗（按日期与省份查节俗）

一个单文件网页：选一个日子、选一个省份，就能看到那天全国正在办的非遗节俗。
**数据已内联进 HTML，零外部依赖，双击 `index.html` 即可打开。**

> 这份是从个人开发目录（`D:\work\wb\查寝`）整理出来的完整版本，源码、数据、成品、截图都在这里，队友直接取用。

---

## 目录结构

```
heritage-calendar/
├─ index.html          成品。单文件，数据内联，可直接打开或部署
├─ src/
│  ├─ gen_feiyi.py     数据生成脚本：农历 / 节气 → 公历，输出 data.json
│  ├─ data.json        生成结果：30 条活动的 2024–2030 日期表 + 农历月首表
│  ├─ template.html    页面模板，第 262 行 const DATA = __DATA__; 是数据占位
│  └─ build.py         把 data.json 注入模板，生成 index.html
└─ previews/           8 张界面截图（桌面端，含匹配结果与空结果两种状态）
```

## 数据覆盖

- **30 条**非遗节俗活动，时间跨度 **2024–2030**
- 字段：名称、省份（可多值）、地点、类别、级别、农历日期、简介、逐年公历起止日期
- 类别：祭祀 / 节庆 / 民俗 / 传统舞蹈
- 级别：人类非遗代表作 / 国家级 / 省级 / 多地非遗
- 匹配逻辑：先「日期 + 省份」精确匹配；查不到则保留日期、放宽地域；再不行保留省份、放宽到未来三个月

## 日期怎么算的（口径说明）

| 类型 | 算法 | 例子 |
|---|---|---|
| 农历固定日 | `lunardate`（紫金历）换算 | 正月十六 → 伏羲春祭 |
| 农历区间 | 起止两日各换算 | 二月初二至三月初三 → 淮阳太昊陵庙会 |
| 节气 | 天文近似公式 `int(yy*0.2422+C) - int(yy/4)` | 清明 → 都江堰放水节；夏至 → 公祭伏羲 |
| 农历整月 | 该月初一 → 下月初一前一天 | 十月 → 瑶族盘王节 |
| 非农历历法 | 逐年手工给定 | 雪顿节（藏历）、开斋节 / 古尔邦节（伊斯兰历，公历逐年提前约 11 天） |

## 改数据 / 重新生成

在 `src/` 目录下：

```bash
pip install lunardate      # 只有生成数据时需要，成品页面不依赖
python gen_feiyi.py        # 重新算日期，覆盖 data.json
python build.py            # 注入模板，生成上一层的 index.html
```

新增一条活动，就在 `gen_feiyi.py` 里追加一个 `add(...)`：

```python
add(id="xxx", name="活动名", provs=["浙江省"], place="某市 · 某地",
    cat="节庆", level="国家级非遗", lunar="正月十五", rule=("l", 1, 15, 1), icon="🏮",
    desc="一句话说明。")
```

`rule` 支持 5 种写法（脚本第 38–41 行有注释）：

| 写法 | 含义 |
|---|---|
| `("l", 月, 日, 天数)` | 农历某日起，持续 N 天 |
| `("r", (月1,日1), (月2,日2))` | 农历区间 |
| `("qm",)` / `("xz",)` | 清明 / 夏至 |
| `("month", 月)` | 农历整月 |
| `("fixed", {年份: "MM-DD"})` | 逐年指定公历日期 |

覆盖年份改脚本开头的 `Y0, Y1`（当前 `2024, 2030`）。

## 队友可以怎么用

1. **查资料时对时间**——直接双击 `index.html`，比翻百度百科快。
2. **当独立页放进站点**——整个文件夹拷进 `site/` 下即可，无外链、无 fetch、不受 `file://` 跨域限制，和现有赛规（不用第三方库）不冲突。
3. **只要数据**——`src/data.json`，`events[].dates` 是 `{s, e}` 形式的公历区间，可直接喂给别的页面或图表。

## 两点提醒

- **数据是人工整理的，不是官方口径。** 页面底部已注明换算依据；要正式上线，日期和级别建议跟当地文旅局 / 非遗保护中心再核一遍，尤其「农历十月（各地择日）」这类本身就不固定的条目。
- **样式是成品自带的**，改配色请动 `src/template.html` 里的 `:root` 变量（第 8–22 行），改完重跑 `build.py`，不要直接改 `index.html`，否则下次生成会被覆盖。
